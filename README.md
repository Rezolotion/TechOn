# 🚀 TechOn

پروژه یکپارچه **TechOn** - پلتفرم هوشمند تجارت الکترونیک، رزرواسیون آنلاین فضای کار اشتراکی، سالن همایش، تشریفات کافه و مدیریت مالی سهم درآمد (۱۰ الی ۱۵ درصد).

---

## 🌐 لینک دمو و نسخه زنده پلتفرم (دائمی و پایدار)
👉 **[https://rezolotion.github.io/TechOn/](https://rezolotion.github.io/TechOn/)**

* **ویژگی‌ها:** قابل دسترسی از روی تمامی گوشی‌ها و سیستم‌ها در سراسر جهان، سرعت بالا (GitHub CDN)، پشتیبانی کامل از حالت شب/روز (Dark/Light)، و سوئیچ ۱-کلیکه بین نقش‌های کاربری.

## 📑 بخش‌ها و مستندات پروژه

### ۱. [سند توافقات تجاری و مدل درآمدی](docs/business-contract.md)
- **مدل مشارکت:** سهم ۱۰ الی ۱۵ درصد از فروش آنلاین (در صورت پوشش کامل ریسک توسعه توسط پیمانکار).
- **تفکیک وظایف:**
  - **پیمانکار:** طراحی، توسعه پلتفرم، زیرساخت و تحویل ابزارهای مدیریت محتوا (CMS Tools).
  - **کارفرما:** تولید و مدیریت محتوا، بازاریابی، سئو و اجرای کمپین‌های تبلیغاتی.

### ۲. [جعبه ابزار، اسکیل‌ها و ماژول‌های اکوسیستم](docs/ecosystem-tools.md)
| ابزار / مهارت | کاربرد در پروژه | مخزن / لینک |
| :--- | :--- | :--- |
| **PersianLabs UI** | کامپوننت‌های بومی فرانت‌اند فارسی (RTL، شتاب، شبا، تاریخ شمسی، قیمت) | [persianlabs/ui](https://github.com/persianlabs/ui) |
| **Hermes Pocket** | کلاینت کاتلین/اندروید جهت اتصال و مدیریت موبایلی ایجنت‌ها | [traveler3022/Hermes-Pocket](https://github.com/traveler3022/Hermes-Pocket) |
| **OpenWiki** | مستندسازی خودکار کدبیس و ساخت پایگاه دانش هوشمند (توسعه LangChain) | [langchain-ai/openwiki](https://github.com/langchain-ai/openwiki) |
| **Salsi** | اسکیل ویرایش و پارسی‌سازی متن‌ها با حفظ کدهای فنی (واژه‌نامه پاسبان) | [pooooooriya/salsi](http://github.com/pooooooriya/salsi) |
| **Ophel Atlas** | سازمان‌دهی چت‌های هوش مصنوعی، تگ‌گذاری، جستجو و بانک پرامپت | [urzeye/ophel](https://github.com/urzeye/ophel) |
| **Focus Friendly** | حفظ پایداری کانتکست و تصمیمات در طول مکالمات و نشست‌های کاری | [yappologistic/focus-friendly](https://github.com/yappologistic/focus-friendly) |
| **Design Oracle** | مهندسی معکوس و تحلیل کامل رنگ، فونت و ساختار UI با Playwright | [jomvick/design-oracle](https://github.com/jomvick/design-oracle) |
